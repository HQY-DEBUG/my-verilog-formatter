# 彩虹缩进集成实施计划

**目标：** 内置 indent-rainbow v8.3.1，支持缩进背景色、细线模式、错误及 Tab/空格混用标记，沿用全部 11 项设置。

**方案：** 沿用现有编辑工具集成结构，固定上游提交 `4c78a0c3a9be6617c96891f7a40f2ad365c845ce`，在 `vendor/indent-rainbow/` 保留源码、manifest 和 MIT 许可。使用现有 esbuild 构建桌面与 Web 组件，已有启用的原扩展时复用。相较依赖用户另装或独立重写，此方案保持现有设置和离线使用习惯。

**约束：** 保持 VS Code ^1.95.0，不增加 npm 运行依赖，不修改文件内容或默认编辑器设置；版本更新为 2.6.0，沿用现有正式发布流程。

## 执行顺序

1. 先补充运行时接入测试，确认未接入时失败。
2. 添加上游快照和必要适配；测试空格/Tab、混用、错误缩进、语言过滤、忽略正则、配置更新、分屏与资源释放。
3. 合并 11 项中文配置，接入桌面/Web 构建，更新使用说明、来源及版本记录。
4. 执行编译、完整测试和差异检查，检查 VSIX 身份、资源与排除项。
5. 完成代码复核，提交并推送 main，等待云端构建成功后推送 v2.6.0，核验 Marketplace 版本及本地最新安装包。

## 重点验证

非 global 或零长度忽略正则不会挂起；无效正则和空颜色列表有明确处理；切换到被排除语言会清除所有标记；更新 tabSize 或配置后可见编辑器及时刷新；停用会取消定时器并释放装饰器及事件；已有原扩展时不重复绘制；浏览器构建不依赖 Node 模块。
